### [Capstone Project — Cybersecurity Measures in Sports Betting Platforms](./capstone-project)
**MFA · IDS · Fraud Monitoring · NIST CSF · MITRE ATT&CK**

Graduate capstone analyzing how multi-factor authentication, intrusion detection, and fraud monitoring improve security on online sports-betting platforms. Built a fully simulated sportsbook environment across 5 VMs (Windows 10 user, Ubuntu app + DB, Kali monitoring, Ubuntu logging), ran credential stuffing / network intrusion / fraudulent-transaction scenarios against baseline and hardened configurations, and quantified the lift:

- **MFA:** 93% reduction in successful account compromises (30% → 2%)
- **IDS:** detection rate 54% → 89%, MTTD 14 min → 3 min
- **Fraud detection:** accuracy 68% → 92%, detection time 6 min → 2 min

Findings mapped to NIST CSF (Protect / Detect / Respond / Recover) and MITRE ATT&CK techniques (T1078, T1110, T1595, T1539, T1565).
