# Portfolio

My cybersecurity projects, capstone, and internship work.

## 🌐 Portfolio Website

This repo doubles as a deployable portfolio website for my M.S. capstone,
**An Analysis of Cybersecurity Measures in Sports Betting Platforms** — a bold-brutalist
single-page case study with an animated results dashboard, MITRE ATT&CK technique cards,
and a terminal-style intro.

### Deploying to Vercel

1. Go to [vercel.com/new](https://vercel.com/new) and import this repository.
2. Framework preset: **Other** (it's a plain static site — no build step needed).
3. Leave the root directory, build command, and output directory at their defaults.
4. Click **Deploy**. Done.

### Structure

- `index.html` — the website
- `assets/` — styles, scripts, and the downloadable full capstone paper
- `capstone-project/` — capstone source materials
- `internship-plasser-american/` — Plasser American internship documentation
